# Bio Armonía Landing Page

Proyecto React + Vite listo para publicar en Vercel.

## Editar datos principales

En `src/App.tsx`:

```ts
const whatsappNumber = '50688970499';
const instagramUrl = 'https://www.instagram.com/bio_armonia_corporal';
const facebookUrl = 'https://www.facebook.com/BIOArmoniaCorporal';
```

Cambiá el número de WhatsApp por el real si hace falta.

## Correr localmente

```bash
npm install
npm run dev
```

## Publicar en Vercel

1. Descomprimir este ZIP.
2. Entrar a Vercel.
3. Add New Project.
4. Upload o Import.
5. Subir la carpeta descomprimida.
6. Deploy.
